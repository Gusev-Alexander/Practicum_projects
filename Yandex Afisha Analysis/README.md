## 🎯 Цели анализа  

Проект направлен на комплексный анализ данных сервиса **Яндекс Афиша** за период с **1 июня по 30 ноября 2024 года**.

Цели:
- Понять причины роста заказов осенью и снижения среднего чека.
- Исследовать предпочтения пользователей по типам мероприятий, возрастным рейтингам и устройствам.
- Проанализировать ежедневную активность пользователей: DAU, средний чек, заказы на пользователя.
- Оценить влияние региона и партнёра на продажи.
- Проверить 2 гипотезы:
  1. Пользователи, работающие только с **мобильных устройств**, делают **больше заказов**, чем те, кто использует десктоп.
  2. Средний **интервал между заказами** у мобильных пользователей **дольше**, чем у десктопных.

## 🗂️ Используемые данные  

Проект основан на трёх датасетах:
- `final_tickets_orders_df.csv` — информация о заказах (дата, сумма, кол-во билетов).
- `final_tickets_events_df.csv` — сведения о мероприятиях (тип, жанр, регион).
- `final_tickets_tenge_df.csv` — курс тенге к рублю для конвертации.

## 📈 Основные результаты

### 🌱 Сезонность
- 📈 Кол-во заказов с июня по октябрь выросло на **67%**.
- 💸 Средняя стоимость билета осенью снизилась на **6.7%**.

### 📱 Устройства
- **Mobile** — около **80%** всех заказов.
- Мобильные пользователи совершают на **34% больше заказов**.
- Интервал между заказами у мобильных — **дольше**, чем у десктопных.

### 🎟️ Типы мероприятий
- Летом лидеры — концерты (**32%**), театр, спорт.
- Осенью — рост популярности театра и семейных мероприятий (**0+, 6+**).

### 📍 Регионы
- **Каменевский регион** — лидер по выручке (**37%**).
- Также активны: **Североярская область**, **Озернинский край**.

### 🤝 Партнёры
- Топ по выручке: **"Билеты без проблем"**, **"Мой билет"**.
- **"Лови билет!"** — много мероприятий, но низкая выручка.
