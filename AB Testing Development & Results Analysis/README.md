## 🎯 Цель проекта  
Проверить гипотезу о том, что **новый алгоритм рекомендаций** увеличивает долю "успешных сессий" (пользователь просматривает 4+ страниц) по сравнению с текущим алгоритмом.  

---

## 📌 Задачи исследования  
1. **Подготовка к A/B-тесту**  
   - Рассчитать необходимый размер выборки и длительность теста.  
   - Проверить корректность распределения пользователей по группам.  

2. **Мониторинг теста**  
   - Проанализировать данные за первые дни теста.  
   - Убедиться в стабильности метрик.  

3. **Анализ результатов**  
   - Сравнить доли успешных сессий в группах A и B.  
   - Проверить статистическую значимость различий.  

4. **Формулировка рекомендаций**  
   - Принять решение о внедрении нового алгоритма.  

---

## 🗂️ Используемые данные  
Проект использует три датасета:  

| Датасет | Описание |  
|---------|----------|  
| `sessions_project_history.csv` | Исторические данные о сессиях (2025-08-15 – 2025-09-23). |  
| `sessions_project_test_part.csv` | Данные за первый день теста (2025-10-14). |  
| `sessions_project_test.csv` | Полные данные теста (2025-10-14 – 2025-11-02). |  

**Ключевые поля**:  
- `session_id` — уникальный идентификатор сессии.  
- `user_id` — идентификатор пользователя.  
- `session_date` — дата сессии.  
- `page_counter` — количество просмотренных страниц.  
- `test_group` — группа теста (A/B).

## 📈 Ключевые результаты  

### 🔍 Основные выводы  
1. **Распределение пользователей по группам**  
   - Группы A и B содержат 49.8% и 50.2% пользователей соответственно.  
   - Разница несущественна (менее 1%), тест проведен корректно.  

2. **Доля успешных сессий**  
   - В группе B доля успешных сессий выше на **7.2%** (p-value = 0.0017).  
   - Эффект статистически значим (уровень значимости 5%).  

3. **Динамика метрик**  
   - Новый алгоритм показал устойчивый рост доли успешных сессий на протяжении теста.
