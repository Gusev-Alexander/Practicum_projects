## 🎯 Цели проекта

Проект направлен на проверку гипотезы о том, что **осенью 2024 года пользователи из Санкт-Петербурга в среднем проводят больше времени за чтением и прослушиванием книг в приложении "Яндекс Книги", чем пользователи из Москвы**.

---

## 📌 Задачи исследования

- Подготовить и предобработать данные о пользователях из Москвы и Санкт-Петербурга.
- Проверить гипотезу с использованием статистических методов (t-тест).
- Интерпретировать результаты и сделать выводы.

---

## 🗂️ Используемые данные

Данные содержат информацию о пользователях Яндекс Книг из Москвы и Санкт-Петербурга за период с 1 сентября по 11 декабря 2024 года. Структура данных:

| Поле         | Тип      | Описание                                   |
|--------------|----------|--------------------------------------------|
| `city`       | object   | Город пользователя (Москва / Санкт-Петербург) |
| `puid`       | int64    | Уникальный идентификатор пользователя        |
| `hours`      | float64  | Общее количество часов активности            |

## 📈 Результаты анализа

### 🔍 Гипотеза:
> Пользователи из Санкт-Петербурга проводят в среднем больше времени в приложении "Яндекс Книги", чем пользователи из Москвы.

### ✅ Метод:
- Выполнен односторонний t-тест для сравнения средних значений активности (часов) между группами.
- Уровень значимости: 5% (`alpha = 0.05`).

### 📊 Результаты:
- T-статистика: `0.609`
- P-value: `0.271`

### ❌ Вывод:
- Так как p-value > 0.05, **нулевую гипотезу отвергнуть нельзя**.
- Нет статистически значимого доказательства того, что пользователи из Санкт-Петербурга проводят больше времени в приложении, чем пользователи из Москвы.

## 📝 Аналитическая записка

### 🧪 Тип теста и уровень значимости
- Использован **t-тест для независимых выборок**.
- Уровень значимости: `alpha = 0.05`.

### 📊 Результаты теста
- **P-value**: `0.271`.
- **T-статистика**: `0.609`.

### 🧠 Интерпретация
- Нулевая гипотеза не отвергнута. Это означает, что мы **не можем доказать**, что пользователи из Санкт-Петербурга проводят больше времени в приложении, чем пользователи из Москвы.
